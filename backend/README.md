# Mediscan - Python Backend

## Project Description
Mediscan is a smart prescription digitization and medical diagnosis system.

## Backend Technology
- Python
- Flask
- REST API
- Machine Learning

## Backend Structure
- app.py - Main Flask application
- routes/ - API routes
- services/ - Business logic
- utils/ - Utility functions
- uploads/ - Uploaded prescription files

## Installation

Install the required packages using:

pip install -r requirements.txt

## Run Backend

python app.py
